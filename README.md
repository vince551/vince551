## 🧬 About Me

I'm **Vincent Odhiambo**, a Kenyan developer who enjoys turning ideas into real, usable digital products.

My work sits at the intersection of **software, design, education and creativity**. I build responsive websites, platforms, PWAs and interactive experiences while continuously exploring full-stack engineering, Linux, cybersecurity and game development.

Beyond technology, I'm interested in **architecture, CAD, youth leadership, children's rights, education and football**. I want the things I build to solve actual problems and create opportunities.

> **Code is the medium. Useful products are the outcome.**

## ⚡ My Build Philosophy

```text
       ┌───────────────┐
       │     IDEA      │
       └───────┬───────┘
               ↓
       ┌───────────────┐
       │   UNDERSTAND  │  Find the real problem
       └───────┬───────┘
               ↓
       ┌───────────────┐
       │     DESIGN    │  Shape the experience
       └───────┬───────┘
               ↓
       ┌───────────────┐
       │     BUILD     │  Turn it into reality
       └───────┬───────┘
               ↓
       ┌───────────────┐
       │      TEST     │  Break it before users do
       └───────┬───────┘
               ↓
       ┌───────────────┐
       │     POLISH    │  Sweat the details
       └───────┬───────┘
               ↓
       ┌───────────────┐
       │      SHIP     │  Put it in people's hands
       └───────┬───────┘
               ↓
             REPEAT
```

I care about **functionality, visual quality, responsiveness, accessibility, performance and the details users actually notice**.
